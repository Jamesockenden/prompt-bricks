# Prompt Brick Library

A modular collection of lightweight, reusable **prompt bricks** designed to be combined into larger workflows across the Software Development Life Cycle (SDLC).

---

## 🧱 What is a Prompt Brick?

A **prompt brick** is a small, single purpose prompt snippet focused on solving one specific task such as writing unit tests, reviewing pull requests, generating API specs, or drafting release notes. 

Rather than relying on monolithic prompts, you can stack and compose these bricks to fit your exact engineering workflow.

---

## 🚀 How to Use

1. **Browse the Bricks:** Explore the repository folders (e.g., `requirements/`, `architecture/`, `testing/`, `code-review/`).
2. **Combine Bricks:** Pick the individual snippets relevant to your goal and chain them together.
3. **Execute:** Feed the combined prompt into your AI coding agent (e.g., Copilot, Claude, ChatGPT).

```text
[ Brick: Security Audit ] + [ Brick: Unit Test Generator ] + [ Your Source Code ]
